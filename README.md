# Hemant Kumar Singh — Portfolio

The source for Hemant's project-focused developer portfolio.

![Portfolio preview](public/portfolio-preview.png)

## Featured work

- Advance Online Chatbot
- Blue Carbon Registry
- Mini AlgoChat

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Vercel

## Local development

```sh
corepack pnpm install
corepack pnpm dev
```

Open `http://localhost:3000`.

## Verification

```sh
corepack pnpm check
```

This audits dependencies, runs TypeScript validation, and creates a production build.
